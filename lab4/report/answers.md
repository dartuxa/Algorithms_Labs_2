### 1. What is a higher-order function?

A higher-order function is a function that either takes one or more functions as arguments or returns a function as its result.

### 2. What is the difference between map and list comprehension?

```map``` is a functional approach that applies a transformation to an entire iterable and returns an iterator , whereas list comprehension is a more readable Pythonic syntax that can perform both transformation and filtering in a single expression to create a new list.

### 3. What is a decorator?

A decorator is a function that takes another function as an argument and extends or modifies its behavior without explicitly changing its source code.

### 4. What is the difference between a simple decorator and a decorator with arguments?

A simple decorator directly wraps a function , while a decorator with arguments requires an extra layer of nesting (a decorator factory) to first accept the parameters before returning the actual decorator.

### 5. Why is caching useful?

Caching is useful because it stores the results of expensive or frequent computations, allowing the program to reuse them later instead of recalculating, which significantly improves performance-especially in recursive functions.
