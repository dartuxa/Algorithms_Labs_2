# Lab 03: Functions as Objects

This lab explores Python functions as first-class objects, demonstrating how they can be assigned to variables, passed as arguments, and used to create closures.

### System Requirements

- Python version: 3.10 or newer (required for the match operator).

- Dependencies: No external libraries required.

### Project Structure

```text
lab3/
├── README.md            # Instructions and project description
├── requirements.txt     # List of dependencies (empty)
├── src/                 
│   └── lab3.py          # Lab
└── report/              # Reports and explanations
    └── answers.md       # Answers to control questions
```

### Task Descriptions

The project consists of the following functional blocks :

- Task A: Implementation of ```apply_twice``` to execute a function on an argument two times.

- Task B: Sorting a list of tuples by age and name using ```lambda``` expressions.

- Task C: A function factory (```make_multiplier```) that returns specialized multiplier functions.

- Task D: A counter implementation utilizing closures to maintain internal state.

- Task E: Comparison of identical logic implemented via ```def``` and ```lambda```.

- Task F: A processing pipeline for filtering even numbers, squaring them, and computing the sum.

### Execution Instructions

To run the laboratory work code, execute the following command from the project root directory :
```text
python src/lab3.py
```
